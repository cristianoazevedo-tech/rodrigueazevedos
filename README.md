# Central de Utilidades

Projeto Integrador — Programação Web I.

Etapas 1 e 2: fundamentos de JavaScript, arrays e objetos no divisor de despesas.

Abra `index.html` no navegador para executar o projeto. As interações das etapas 1 e 2 são feitas com `prompt()` e `alert()` conforme a proposta da atividade.
